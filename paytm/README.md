# Paytm Application

For full documentation, architecture details, Docker instructions, API reference, and setup guides, please refer to the main repository [README.md](../../README.md).

### Quick Commands

- **Backend**: `cd backend && npm install && node main.js` (Runs on `http://localhost:3000`)
- **Frontend**: `cd frontend && npm install && npm run dev` (Runs on `http://localhost:5173`)
- **Database**: Run MongoDB in Docker: `docker run -d --name mongodb -p 27017:27017 mongo:latest`
